# Console-Based-Tetris-Clone

A block stacking tetris game that runs in the terminal, written in object-oriented C++.

**Features:**
* All 7 tetrominoes (I, O, T, S, Z, J, L) with matrix-based rotation
* Soft drop, hard drop and a next piece preview
* Menu, pause and game over screen

**Controls:**
Key	Action
Left/A	Move left
Right/D	Move right
Up/W	Rotate clockwise
Down/S	Soft drop
Space	Hard drop
P	Pause/resume
Enter	Start, resume or play again
Q/Esc	Quit

**Requirements:**
* A C++17 compiler: g++ 7+, clang++, or MSVC (Visual Studio 2017+)
* CMake 3.12+
